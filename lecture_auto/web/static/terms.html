Lecture Auto 이용약관

본 서비스는 슬라이드와 대본을 AI 합성 음성 강의영상으로 만드는 도구입니다. 결과물에는 AI가 합성한 음성이 사용됩니다. 사용자는 결과물을 공개할 때 AI 합성 음성임을 알려야 합니다.

음성 복제와 자료 사용 책임

본인의 음성 또는 음성 주인에게 AI 음성 복제 사용 동의를 받은 파일만 등록할 수 있습니다. 업로드 시 동의 문구, 시각, 계정, 파일 해시를 보관합니다. 타인을 사칭하거나 동의 범위를 벗어나 사용해서는 안 됩니다. 슬라이드와 대본에 대한 사용 권한도 사용자에게 있어야 합니다.

API 사용 비용

사용자가 등록한 본인의 BAZE API 키로 대본과 API 음성을 생성합니다. 사용량과 비용은 해당 API 계정에 청구됩니다. 제작 전에 자료 크기와 대본 길이를 확인해 주세요. 서버는 키를 암호화해 보관하며 화면에는 끝 4자리만 표시합니다.

신고와 사용 중단

권리 침해나 동의 없는 복제가 의심되면 강의 또는 내 음성 화면의 신고 기능으로 대상과 사유를 알려 주세요. 운영자는 신고를 검토하고 음성·강의·계정을 비활성화할 수 있으며, 필요한 경우 자료 삭제와 추가 확인을 요청합니다. 비활성화된 음성과 강의는 새 제작에 사용할 수 없습니다.

데이터 보관과 삭제

자료와 음성은 서비스 운영 중 보관됩니다. API 키와 등록 음성은 설정에서 삭제할 수 있습니다. 강의를 목록에서 삭제해도 제작 파일과 업로드 원본은 서버에 남으며 저장 공간 사용량에 포함됩니다. 계정 및 잔여 자료의 완전 삭제는 신고 기능을 통해 운영자에게 요청해 주세요. 동의와 신고 기록은 분쟁 확인을 위해 보관하며 운영자가 삭제 요청 및 보관 필요성을 검토합니다.

자료의 영구 보관을 보장하지 않습니다. 필요한 결과물은 내려받아 별도로 보관해 주세요. Raon 로컬 음성 엔진은 비상업적 학교 내부 사용 범위에서만 사용합니다.
