반면 슬라이드의 핵심 주장과 생성 대본의 사실관계를 직접 비교하는 별도의 검수 절차는 이번에 확인한 배치 코드에서 찾지 못했습니다.

예를 들어 모든 슬라이드의 시작에 연결 표현을 배치하고, 특정 어미를 일정 비율 이상 사용하도록 요구합니다.
이 방식은 기존에 부족했던 구어체 표현을 늘리는 데 유용할 수 있습니다. 그러나 그것만으로 교수님다운 강의가 만들어지는 것은 아닙니다.

실제 강의에서의 설명 순서, 사례를 제시하는 방식, 질문을 던지는 위치, 중요한 개념을 강조하는 방식까지 반영해야 합니다.
여기서는 기존 문체 프롬프트와 좀 더 유연한 문체 프롬프트를 비교해 볼 수 있습니다. 같은 슬라이드와 같은 내용으로 대본을 생성하고, 교수님이 어느 쪽을 자연스럽게 읽거나 청취할 수 있는지 평가하면 됩니다.
특정 연결 표현을 매 슬라이드마다 강제하는 방식은 완화 후보로 두되, 실제 비교 없이 기존 설정을 바로 폐기할 필요는 없습니다.

현재 구현의 전체 강의 계획과 섹션별 대본 생성 과정에도 시간 예산이 반영되어 있습니다.
하지만 실제 완성 영상 길이를 기준으로 대본의 분량을 검토하고 조정하는 후속 단계는 더 명확하게 만들 필요가 있습니다.
