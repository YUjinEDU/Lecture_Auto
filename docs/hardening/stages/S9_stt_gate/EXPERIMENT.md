- plain "너무 짧다" 불합격 20개 중 **19개가 내용 완전**(초당 7.3–9.7자). 모델의 실제 속도는 정상 조각 중앙값 **7.5자/초**인데 gate는 5.7자/초 가정 → 빠른 정상 발화를 잘림으로 오판.
- 진짜 불량(plain 7개)은 전부 **무음 > 2.8s 또는 CER ≥ 0.28**로 구분됨. 길이 하한은 판별력이 없음.
- 무음 불량은 내용도 틀린 경우(CER 0.6+)라 "무음 압축"으로 살릴 수 없음 → 압축안 폐기.
- 시도 1회: 생성 평균 26.3s, STT 3.3s(+13%).
- 조각 16개 중 plain 시도로 내용 정상본을 얻는 조각 15개(현재 gate로는 9개).
- 기대 효과: 첫 시도 합격률 28% → ~80%, 조각당 시도 ~3회 → ~1.3회 ⇒ 합성 시간 약 절반 이하.
