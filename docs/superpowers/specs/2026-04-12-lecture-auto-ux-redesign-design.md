# Lecture Auto — UX 재설계 스펙

**날짜:** 2026-04-12  
**범위:** `lecture_auto/demo_static/` (index.html, styles.css, app.js)  
**목표:** 실제 교수님 사용 시나리오에 맞게 흐름을 재정비하고, Mobile-first 반응형 레이아웃 적용

---

## 배경 및 문제 정의

현재 UI의 두 가지 핵심 문제:

1. **흐름 불일치**: 설정 탭이 파이프라인/검수 탭 사이에 끼어 있어 "설정이 이미 실행된 결과에 반영되는 건지, 다음 실행에 반영되는 건지" 혼란을 줌
2. **반응형 미지원**: 데스크탑 기준으로만 레이아웃이 짜여 있어 모바일/태블릿에서 깨짐

**실제 사용 시나리오:**
```
PDF 업로드 → (설정 완료) → 파이프라인 자동 실행 → 슬라이드 검수/편집 → 음성 다운로드
```

---

## 확정된 설계

### 1. 전체 구조

```
홈 화면 (강의 목록 그리드)
  │
  ├─ [새 강의 만들기] 버튼
  │       └─ 생성 모달 (설정 전체 포함) → [파이프라인 시작] → 상세 화면
  │
  └─ 강의 카드 클릭
          └─ 상세 화면
               ├─ 진행상황 탭 (기본 진입)
               ├─ 슬라이드 검수 탭
               └─ 다운로드 탭
```

**제거 항목:**
- `설정` 탭 → 생성 모달로 이동
- `내보내기` 탭 → `다운로드` 탭으로 통합·단순화

**설정 변경 = 재실행:** 설정을 바꾸고 싶으면 홈으로 돌아가서 새 강의 만들기로 재시작. 탭에서 설정을 수정하는 흐름 제거.

---

### 2. 생성 모달 (새 강의 만들기)

모든 설정을 한 화면에 담는 단일 모달. 섹션 구성:

| 섹션 | 항목 | 필수 여부 |
|------|------|-----------|
| 파일 업로드 | PDF 드래그앤드롭 / 클릭 선택 | 필수 |
| 기본 정보 | 강의 제목, 목표 시간(분) | 제목 선택, 시간 필수 |
| 스크립트 설정 | 청중 대상(텍스트), 설명 스타일(강의식/대화식/간결 토글) | 선택 |
| 음성 설정 (TTS) | 녹음 또는 파일 업로드, 생략 시 기본 음성 사용 | 선택 |
| 고급 옵션 | VLM 슬라이드 시각 분석 체크박스 | 선택 |

**레이아웃:**
- 모바일: `position: fixed; inset: 0` 풀스크린 시트 (상단 헤더 + 스크롤 가능 본문)
- 데스크탑: `max-width: 560px` 중앙 다이얼로그 (현재 방식 유지)

---

### 3. 상세 화면 — 탭 구성

#### 탭 1: 진행상황 (기본 진입 탭)

- 5개 스테이지 카드: `PDF 파싱` → `슬라이드 렌더링` → `VLM 분석` → `스크립트 생성` → `TTS 변환`
- 각 카드 상태: 대기(회색) / 진행 중(초록 테두리 + 애니메이션) / 완료(채워진 초록) / 실패(빨강)
- 실행 로그: 기본 **접힌 상태**, "로그 보기 ▼" 클릭 시 펼침 (monospace, 스크롤)
- 완료 시 검수 탭으로 자동 이동 + 토스트 알림

#### 탭 2: 슬라이드 검수

**데스크탑 (≥768px):**
- 좌측: 썸네일 스트립 (세로 스크롤, 고정 너비 160px)
- 우측: 선택된 슬라이드 스크립트 편집 영역 + TTS 승인 버튼

**모바일 (<768px):**
- 상단: 썸네일 가로 스크롤 스트립 (고정 높이, 터치 스크롤)
- 하단: 스크립트 편집 영역 + TTS 승인 버튼

#### 탭 3: 다운로드

- 슬라이드별 음성 파일 목록 (파일명 + 재생 버튼 + 개별 다운로드)
- 전체 일괄 다운로드 버튼 (ZIP)

---

### 4. 반응형 전략 (Mobile-first)

CSS를 모바일 기준으로 재작성, 데스크탑은 미디어쿼리로 확장.

| 요소 | 모바일 (<768px) | 데스크탑 (≥768px) |
|------|----------------|------------------|
| 홈 그리드 | 1열 | 2열 → 3열 (≥1024px) |
| 탭 바 | 가로 스크롤 허용 | 고정 |
| 생성 모달 | 풀스크린 시트 | 중앙 다이얼로그 (max-width: 560px) |
| 검수 레이아웃 | 썸네일 상단 가로 스크롤 + 스크립트 하단 | 좌우 2열 (썸네일 160px 고정) |
| 스테이지 카드 | flex-wrap (줄 바꿈) | flex-wrap (필요 시) |

**브레이크포인트:** `768px` (tablet/desktop 경계), `1024px` (3열 그리드)

## API 계약

**변경 없음.** 백엔드 API는 이미 필요한 모든 필드를 지원한다.

| 엔드포인트 | 관련 변경 | 비고 |
|-----------|-----------|------|
| `POST /demo/api/jobs` | 모달에서 `audience`, `explanation_style`, `use_vlm` 필드 전송 추가 | 이미 Form 파라미터로 존재 (기본값 있음) |
| `POST /demo/api/jobs/{id}/voice-reference` | 모달에서 음성 선택 → job 생성 후 즉시 자동 업로드 | 별도 요청 유지; job_id 발급 후 순차 실행 |

**음성 업로드 2단계 흐름 (모달 내):**
1. 사용자가 모달에서 음성 파일 선택 또는 녹음 → `state.pendingVoiceBlob`에 저장
2. [파이프라인 시작] 클릭 → `POST /demo/api/jobs` → job_id 수신
3. `state.pendingVoiceBlob`이 있으면 즉시 `POST /demo/api/jobs/{id}/voice-reference` 자동 전송
4. 완료 후 상세 화면으로 이동

## 변경 범위

| 파일 | 변경 내용 |
|------|-----------|
| `index.html` | 설정 탭(`data-tab="settings"`) 제거, 내보내기→다운로드(`data-tab="export"` 유지, 라벨만 변경), 모달에 청중/스타일/음성 섹션 추가, 모바일 모달 구조 추가, 로그 섹션 초기 숨김 |
| `styles.css` | Mobile-first 전면 재작성, `@media (min-width: 768px)` / `(min-width: 1024px)` 구조화, 모달 풀스크린 모드 추가 |
| `app.js` | `TABS` 배열에서 `'settings'` 제거 (`data-tab` 키값 유지: `pipeline`, `review`, `export`), 생성 폼에 audience/explanation_style 바인딩 추가, 음성 파일 2단계 업로드 로직, 로그 접힘 토글, 완료 시 탭 자동 전환 |

**탭 `data-tab` 속성값 (JS 내부 키):**
- `pipeline` — 표시 라벨: "진행상황" (기존 "파이프라인" → 라벨만 변경)
- `review` — 표시 라벨: "슬라이드 검수" (변경 없음)
- `export` — 표시 라벨: "다운로드" (기존 "내보내기" → 라벨만 변경)
- `settings` — **제거**

**완료 시 자동 탭 전환 조건:**
폴링 응답에서 `job.status === 'completed'`가 되는 순간 `switchTab('review')` 호출. 토스트 알림 표시. 폴링 로직 자체는 변경 없음.

**로그 초기 상태:**
`#eventList` 부모인 `.log-section`에 `hidden` 클래스 기본 적용. "로그 보기" 버튼 클릭 시 토글. 로그 내용이 있어도 기본 숨김.

## 변경하지 않는 것

- FastAPI 백엔드 API 엔드포인트 스키마
- 홈 ↔ 상세 SPA 라우팅 로직 (`window.location.hash` 방식 유지)
- 슬라이드 검수 핵심 기능 (썸네일 클릭 → 스크립트 표시, TTS 승인)
- 강의 목록 폴링 로직
- 슬라이드 근거 모달 (`evidenceModal`)
