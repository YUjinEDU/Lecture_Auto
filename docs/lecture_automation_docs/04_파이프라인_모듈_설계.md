```text
  io/
  ppt/
  render/
  preprocess/
  vlm/
  script/
  schemas/
  llm/
  utils/
  eval/
```

## 2. 모듈 상세
### pipeline/
- orchestrator.py: 전체 단계 제어
- stages.py: 각 단계 등록
- job_state.py: 체크포인트와 재실행 정보 관리

### ppt/
- loader.py: 입력 파일 로딩
- parser.py: 슬라이드 텍스트/shape 추출
- notes_extractor.py: 발표자 노트 추출
- slide_manifest.py: JSON 산출물 작성

### render/
- libreoffice_renderer.py: PPTX -> PDF
- pdf_to_images.py: PDF -> PNG

### preprocess/
- slide_classifier.py: slide type 분류
- context_window.py: 앞뒤 슬라이드 문맥 묶기
- token_budget.py: 모델 입력 길이 제어

### vlm/
- client.py: VLM 호출
- prompts.py: 프롬프트 템플릿
- visual_notes.py: visual note 생성/후처리
- validation.py: 출력 검증

### script/
- planner.py: 전체 강의 흐름 설계
- writer.py: 슬라이드별 스크립트 작성
- duration_controller.py: 목표 시간 맞춤
- coherence_refiner.py: 흐름 보정
- validator.py: 출력 검증

### schemas/
- slide.py
- visual_note.py
- script.py
- job.py
