# 07. 디렉터리 및 환경설정 표준

## 1. IDE 작업 표준
- Python 3.11 이상
- Poetry 또는 uv 기반 환경 관리
- `.env`에 모델 경로와 캐시 경로 분리
- `configs/`와 `src/`를 엄격히 분리

## 2. 필수 환경변수 예시
```bash
PROJECT_ROOT=/workspace/lecture_automation
DATA_ROOT=/workspace/lecture_automation/data
MODEL_ROOT=/workspace/models
JOB_ROOT=/workspace/lecture_automation/data/work
VLM_MODEL_NAME=qwen2.5-vl
LLM_MODEL_NAME=gpt-or-local-llm
```

## 3. 권장 실행 커맨드
```bash
python -m src.main run --pptx data/raw/sample.pptx --audience "학부 3학년" --duration 20
python -m src.main resume --job-id job_20260308_001 --stage vlm
python -m src.main export-review --job-id job_20260308_001
```

## 4. Git 관리 원칙
- 원본 데이터와 생성물은 분리
- `data/work/`는 기본적으로 Git 추적 제외
- `configs/`, `schemas/`, `prompts/`는 추적 대상
