# 05. 개발 로드맵

## Phase 1. 기본 파이프라인 연결
- PPTX 파싱
- 슬라이드 PNG 렌더링
- slide_manifest.json 저장
- 샘플 1개 종단 실행

## Phase 2. VLM 해설 노트 생성
- 전 슬라이드 visual notes 생성
- JSON 검증
- 유형별 프롬프트 분기

## Phase 3. 최종 스크립트 생성
- 강의 대상/시간 조건 반영
- 슬라이드별 설명문 생성
- 검수용 Markdown 출력

## Phase 4. 품질 개선
- 앞뒤 슬라이드 문맥 반영
- 표/차트/수식 슬라이드 특화 처리
- 오류 재시도 로직

## Phase 5. 후속 연동 준비
- TTS 입력 포맷 정리
- 자막/타임라인용 필드 추가
- Remotion 단계 연동 사전 설계
