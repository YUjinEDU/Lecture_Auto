# 강의 영상 자동 제작 및 교수님 스타일 복제 실행 계획서

- **작성일자**: 2026-09-11
- **목표**: 2개 과목(AI활용현업문제해결, 종합설계) 총 5개 강의 영상(각 약 30분 분량, MP4) 고품질 제작 완료
- **핵심 특징**:
  1. 교수님의 실제 과거 강의 음성(32분)을 `Raon-Speech-9B`의 내장 STT로 전사하여 **교수님 고유의 강의/발화 스타일(어조, 어미, 추임새, 강의 전개 구조)을 정밀 분석 & 스크립트에 반영**
  2. `MultiLLM_LabSearch_2026`의 FactChat Cloud Gateway를 통해 **`gpt-5.6-luna`**로 30분 분량의 고품질 한국어 스크립트 순차 생성
  3. `KRAFTON/Raon-Speech-9B`를 사용한 교수님 음성 클로닝(TTS) 및 고화질 슬라이드 영상(MP4) 합성

## 2. 단계별 상세 실행 계획

### Phase 1: uv 기반 Python 3.11 가상환경 구성

- `uv venv .venv --python 3.11`로 가상환경 구축
- PyTorch (CUDA 12.1), transformers>=4.57.1, accelerate, soundfile, speechbrain 등 필수 패키지 설치
- 프로젝트 기본 의존성(fastapi, pydantic, pymupdf, pdfplumber, pdf2image, python-dotenv, openai 등) 설치

### Phase 2: Raon-Speech-9B 모델 다운로드 및 로드 테스트

- 대용량 저장소(`/mnt/hdd2/models/Raon-Speech-9B`)에 모델 다운로드
- GPU 0 (RTX A6000 48GB)에 bfloat16으로 `RaonPipeline` 로드 검증 (약 18GB VRAM 소요)

### Phase 3: 음성 전처리 (M4A -> WAV) 및 1개 슬라이드 샘플 테스트

- `260911_교수님음성 .m4a` -> WAV 변환 (24kHz 모노)
- `공감과디브리핑-AI활용현업문제해결-2025.m4a` -> WAV 변환
- 1개 슬라이드 샘플 문장 TTS 생성 및 음질/음색 일치도 테스트

### Phase 4: 과거 강의(32분) STT 전사 및 교수님 강의 스타일 분석

- `past_lecture_2025.wav`를 Raon-Speech `pipe.stt()`로 텍스트 전사
- 전사된 텍스트 분석:
  1. 말투/어미 특징 ("~라고 볼 수 있겠죠?", "자, 여러분~", "~해보겠습니다")
  2. 설명 호흡 및 전개 패턴 (개념 -> 일상/현업 예시 -> 질문 던지기 -> 요약)
  3. 학생 대면 어조 및 추임새
- `professor_style_guide.md` 작성 및 스크립트 생성 프롬프트에 주입

### Phase 5: MultiLLM (gpt-5.6-luna) 연동 및 PDF 파이프라인 정비

- FactChat Cloud Gateway (`https://factchat-cloud.mindlogic.ai/v1/gateway`) 연동
- `lecture_auto/llm/openai_client.py`에 base_url 지원 및 `gpt-5.6-luna` 모델 지정
- PDF 직접 렌더링 지원 (`renderer.py`에서 `pdf_to_pngs` 직결)
- 슬라이드당 30분 목표 맞춤 시간/분량 계산 적용

### Phase 6: 5개 과목별 30분 분량 강의 스크립트 순차 생성

- 1번: AI현업 - 02-디자인씽킹 개요 (48장)
- 2번: AI현업 - 03-고객 문제 이해 (33장)
- 3번 & 5번 (동일 본문 42장): AI현업 04번 기본 생성 후, 종합설계 03번은 표지/도입부만 교체
- 4번: 종합설계 - 02_고객 문제 이해 및 정의 (29장)

### Phase 7: Raon-Speech-9B 보이스 클로닝 일괄 합성

- 슬라이드별 텍스트를 교수님 목소리로 WAV 합성
- 3번/5번 중복 슬라이드는 생성된 오디오를 재사용하여 합성 시간 50% 단축

### Phase 8: ffmpeg 슬라이드-오디오 동기화 및 최종 MP4 렌더링

- 각 슬라이드 PNG + WAV를 무손실 병합하여 최종 30분 분량 MP4 5개 생성
