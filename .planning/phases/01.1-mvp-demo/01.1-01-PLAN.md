    **Functions:**

    1. `load_vlm(model_path: str = "Qwen/Qwen3-VL-8B-Instruct") -> vllm.LLM` — Load Qwen3-VL via vLLM offline inference. Use `vllm.LLM(model=model_path, dtype="auto", max_model_len=4096, trust_remote_code=True)`. Return the LLM instance.

    2. `build_vlm_prompt(slide: SlideRecord, rendered_dir: Path) -> dict` — Build a multimodal prompt containing:
       - The slide PNG image path from `rendered_dir / slide.png_path`
       - All parsed text extracted from slide.shapes (concatenated paragraphs full_text for shapes where has_text=True), prefixed with "Parsed text from this slide:" — this implements text-grounded prompting per VLM-02 to prevent hallucination
       - System instruction requesting JSON output with the VlmNote schema fields

       - For each slide, call `build_vlm_prompt`
       - Use `llm.generate()` with `SamplingParams(temperature=0.3, max_tokens=1024)`
       - Parse JSON output from each response, validate with VlmNote model
       - If JSON parse fails, retry once with temperature=0.1
       - Save each note to `vlm_dir / f"vlm_note_{slide.slide_number:03d}.json"`
       - Return list of VlmNote objects

    **Important implementation details:**
    - Import: `from vllm import LLM, SamplingParams`
    - Use `qwen_vl_utils` for image preprocessing if needed by vLLM Qwen3-VL
    - All file writes use `pathlib.Path.write_text()` with `json.dumps(note.model_dump(), ensure_ascii=False, indent=2)`

    **Pydantic schema (SlideScript):**
    ```python
    class SlideScript(BaseModel):
        slide_index: int
        slide_number: int
        target_seconds: float
        script: str
        keywords: list[str]
        transition_to_next: str
    ```

    **Functions:**

    1. `build_script_prompt(slide: SlideRecord, vlm_note: dict, style: LectureStyle, target_seconds: float, prev_slide: SlideRecord | None, next_slide: SlideRecord | None, prev_script: str | None) -> str` — Build a text prompt for Claude including:
       - System role: "You are a Korean university professor creating lecture scripts."
       - LectureStyle params: density={style.density}, tone={style.tone}, approach={style.approach}
       - Target duration: target_seconds seconds for this slide
       - Current slide: parsed text from shapes + VLM visual notes
       - Previous slide context (if exists): title + previous script excerpt (last 100 chars)
       - Next slide context (if exists): title text
       - Output format: JSON with fields slide_index, slide_number, target_seconds, script, keywords (list of 3-5), transition_to_next
       - Instruction: "Write the lecture script in Korean. Output ONLY valid JSON."

    2. `async def call_claude(prompt: str) -> str` — Call `claude -p` via `asyncio.create_subprocess_exec("claude", "-p", prompt, stdout=PIPE, stderr=PIPE)`. Read stdout, check returncode. Raise RuntimeError on non-zero exit with stderr content. Return stdout decoded as UTF-8.

    3. `async def generate_scripts(slides: list[SlideRecord], vlm_notes: list[dict], manifest: SlideManifest, scripts_dir: Path) -> list[SlideScript]` — Main entry point:
       - Calculate `target_seconds = (manifest.target_minutes * 60) / manifest.slide_count`
       - For each slide sequentially (not parallel — context dependency):
         - Build prompt with prev/next slide context and previous script text
         - Call `call_claude(prompt)`
         - Parse JSON response, validate with SlideScript model
         - Save to `scripts_dir / f"script_{slide.slide_number:03d}.json"`
         - Store script text for next iteration's prev_script context
       - Return list of SlideScript objects

    **Important implementation details:**
    - Use `asyncio.create_subprocess_exec` not `subprocess.run` — async pattern per CLAUDE.md
    - Sequential processing per slide (each depends on previous script for transition context)
    - All file writes: `path.write_text(json.dumps(script.model_dump(), ensure_ascii=False, indent=2))`
    - Log each slide with `logging.getLogger(__name__)`
    - If JSON parse fails from Claude output, attempt to extract JSON from markdown code fence (```json ... ```)
