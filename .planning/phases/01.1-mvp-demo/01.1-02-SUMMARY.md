# Phase 01.1 Plan 02: TTS + Video Assembly Summary

**One-liner:** Qwen3-TTS audio synthesis with voice clone + ffmpeg `-loop 1` / concat demuxer video assembly, 21 unit tests, no GPU required at test time.

## What Was Built

### Task 1: TTS audio synthesis module (Qwen3-TTS with voice clone)

`lecture_auto/pipeline/tts.py` exports:

- `load_tts(model_path)` — loads Qwen3-TTS via transformers; uses lazy import so the module is importable without GPU stack
- `generate_silence(duration_seconds, sample_rate)` — numpy zeros array, used for empty-text slides
- `synthesize_slide(tts_model, text, output_path, voice_ref_path)` — single-slide synthesis; empty/whitespace text → 1 s silence WAV; voice clone via `sf.read(voice_ref_path)` passed as `voice_ref` kwarg
- `synthesize_audio(tts_model, scripts, audio_dir, voice_ref_path)` — main entry point; processes list of `{slide_number, script}` dicts; outputs `audio_NNN.wav` files; returns `list[Path]`

Sample rate: 24000 Hz (Qwen3-TTS native). Sequential processing (GPU memory constraint).

**Tests (tests/test_tts.py):** 10 tests, all pass. Mock strategy: `patch.object(tts_module, "synthesize_slide")` for synthesize_audio tests; direct call with `{"model": MagicMock(), "tokenizer": MagicMock()}` for synthesize_slide silence tests.

Commit: `8559532`

### Task 2: Video assembly module (ffmpeg PNG+WAV to MP4)

`lecture_auto/pipeline/video.py` exports:

- `create_slide_clip(png_path, wav_path, output_path, fps)` — calls `ffmpeg -y -loop 1 -framerate {fps} -i {png} -i {wav} -c:v libx264 -tune stillimage -c:a aac -b:a 192k -pix_fmt yuv420p -shortest -fps_mode vfr {out}`; raises RuntimeError on non-zero exit
- `concat_clips(clip_paths, output_path)` — writes temp concat list, calls `ffmpeg -f concat -safe 0 -c copy`; cleans up temp file in `finally` block
- `assemble_video(png_paths, wav_paths, video_dir, output_path, job_id)` — matches PNG/WAV by slide number extracted from filename suffix; skips slides with missing WAV (logs warning); calls concat; deletes intermediate `clip_NNN.mp4` files after concat

**Tests (tests/test_video.py):** 11 tests, all pass. Mock strategy: `patch("lecture_auto.pipeline.video.subprocess.run")` for create/concat tests; `patch.object(video_module, "create_slide_clip")` + `patch.object(video_module, "concat_clips")` for assemble_video tests.

Commit: `334b492`
