    Create `lecture_auto/pipeline/tts.py` with these components:

    **Functions:**

    1. `load_tts(model_path: str = "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice") -> object` — Load Qwen3-TTS model. Use the transformers-based approach:
       ```python
       from transformers import AutoTokenizer, AutoModelForCausalLM
       tokenizer = AutoTokenizer.from_pretrained(model_path, trust_remote_code=True)
       model = AutoModelForCausalLM.from_pretrained(model_path, trust_remote_code=True, device_map="auto")
       return {"model": model, "tokenizer": tokenizer}
       ```
       Note: The exact Qwen3-TTS API may vary. The executor should check the model card at `https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` for the correct inference API. If vLLM-Omni is simpler, use that instead. The key contract is: text in, WAV samples out.

    2. `generate_silence(duration_seconds: float, sample_rate: int = 24000) -> Path` — Create a silence WAV file using numpy zeros + soundfile. Used for empty script slides.

    3. `synthesize_slide(tts_model: object, text: str, output_path: Path, voice_ref_path: Path | None = None, sample_rate: int = 24000) -> Path` — Synthesize single slide:
       - If text is empty or whitespace-only, generate 1-second silence WAV
       - If voice_ref_path provided, load the reference audio (3-second clip per TTS-02) and pass to model for voice cloning
       - If voice_ref_path is None, use default model voice
       - Write output to output_path using `soundfile.write(output_path, samples, sample_rate)`
       - Return output_path

    4. `synthesize_audio(tts_model: object, scripts: list[dict], audio_dir: Path, voice_ref_path: Path | None = None) -> list[Path]` — Main entry point:
       - For each script dict (must have "slide_number" and "script" keys):
         - output_path = `audio_dir / f"audio_{script['slide_number']:03d}.wav"`
         - Call `synthesize_slide(tts_model, script["script"], output_path, voice_ref_path)`
       - Return list of WAV paths in slide order
       - Log each slide with `logging.getLogger(__name__)`

    **Important implementation details:**
    - Import: `import soundfile as sf` (from soundfile package) and `import numpy as np`
    - Voice clone: Load reference WAV with `sf.read(voice_ref_path)`, pass raw samples to model
    - Sample rate: 24000 Hz (Qwen3-TTS native rate per model card)
    - Do NOT use `scipy.io.wavfile` — use `soundfile` per CLAUDE.md
    - Sequential processing (GPU memory constraint: one slide at a time)

  <action>
    Create `lecture_auto/pipeline/video.py` with these components:

    **Functions:**

    1. `create_slide_clip(png_path: Path, wav_path: Path, output_path: Path, fps: int = 1) -> Path` — Create a single-slide video clip:
       - Run ffmpeg: `ffmpeg -y -loop 1 -i {png_path} -i {wav_path} -c:v libx264 -tune stillimage -c:a aac -b:a 192k -pix_fmt yuv420p -shortest -fps_mode vfr {output_path}`
       - The `-loop 1` keeps the PNG displayed for the duration of the audio
       - The `-shortest` ends when the shorter input (audio) ends
       - Use `subprocess.run(cmd, capture_output=True, text=True, check=False)` then check returncode
       - Raise RuntimeError on non-zero exit with stderr content
       - Return output_path

    2. `concat_clips(clip_paths: list[Path], output_path: Path) -> Path` — Concatenate clips:
       - Write a concat file: `file 'clip_001.mp4'\nfile 'clip_002.mp4'\n...` to a temp text file
       - Run ffmpeg: `ffmpeg -y -f concat -safe 0 -i {concat_file} -c copy {output_path}`
       - Clean up the concat list file
       - Raise RuntimeError on non-zero exit
       - Return output_path

    3. `assemble_video(png_paths: list[Path], wav_paths: list[Path], video_dir: Path, output_path: Path, job_id: str) -> Path` — Main entry point per D-07/D-08/D-09:
       - Create video_dir if not exists
       - For each (png, wav) pair matched by slide number:
         - clip_path = `video_dir / f"clip_{slide_number:03d}.mp4"`
         - Call `create_slide_clip(png, wav, clip_path)`
         - Skip slides where WAV is missing (log warning)
       - Collect all clip paths in order
       - Call `concat_clips(clip_paths, output_path)`
       - Clean up intermediate clip files (delete clip_*.mp4 from video_dir)
       - Return output_path (the final lecture MP4)

    **Important implementation details:**
    - Use `subprocess.run` (not async — ffmpeg is fast per clip, no benefit from async here)
    - Slide number extraction: parse from filename `audio_001.wav` -> 1, match to `slide_001.png`
    - output_path for final MP4: passed in by caller (run.py will set `output/lecture_{job_id}.mp4` per D-09)
    - video_dir: use JobPaths job_dir / "video" (or a temp subdir within artifacts_dir)
    - Log each clip creation and final concat with `logging.getLogger(__name__)`
    - ffmpeg must be available on PATH (system dependency)

    - Intermediate clip files cleanup after concat
    - Non-zero ffmpeg exit raises RuntimeError
