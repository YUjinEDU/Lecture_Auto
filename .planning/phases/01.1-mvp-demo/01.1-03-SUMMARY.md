# Phase 01.1 Plan 03: Interactive CLI Orchestrator Summary

**One-liner:** Interactive `python run.py --pptx file.pptx` CLI that wires all 6 pipeline stages (parse→render→VLM→script→TTS→video) with per-stage [y/n] confirmation and summary JSON output.

## What Was Built

### run.py (296 lines)

Top-level CLI orchestrator for the full PPTX-to-MP4 pipeline. Key design points:

- **argparse** with all required flags: `--pptx`, `--density` (concise/detailed), `--tone` (formal/casual), `--approach` (explanatory/socratic), `--voice`, `--name`, `--subject`, `--audience`, `--minutes`, `--vlm-model`, `--tts-model`
- **6-stage pipeline** with try/except per stage — on error, prints work_dir for inspection and writes partial summary JSON
- **confirm_step()** helper: prompts `[y/n]` after each stage, `""` / `"y"` / `"yes"` continue, anything else aborts gracefully
- **write_summary()**: writes `output/summary_{job_id}.json` with job_id, pptx_file, slide_count, stage_timings, total_seconds, font_warnings, output_mp4, work_dir (plus optional `error` field)
- **sha256_file()**: chunked SHA-256 for manifest integrity
- **Lazy imports**: `from lecture_auto.pipeline.vlm import ...` lives inside `main()` so the file is importable without GPU stack (enabling unit tests)

### lecture_auto/pipeline/__init__.py

Re-exports all 6 stage symbols:
- `parse_pptx`, `render_slides`
- `load_vlm`, `generate_visual_notes`, `VlmNote`
- `generate_scripts`, `SlideScript`, `call_claude`
- `load_tts`, `synthesize_audio`
- `assemble_video`, `create_slide_clip`, `concat_clips`

### tests/test_run.py (45 tests)

Covers CLI helpers only (no GPU required):
- `TestConfirmStep` (10 tests): y/yes/empty=True, n/no/arbitrary=False, EOFError/KeyboardInterrupt=False
- `TestArgParserDefaults` (17 tests): all defaults and choices, invalid values raise SystemExit
- `TestWriteSummary` (12 tests): JSON structure, total_seconds math, error field presence
- `TestStageTiming` (2 tests): accumulation and rounding
- `TestSha256File` (4 tests): consistency, known SHA-256 of empty bytes, hex string format
