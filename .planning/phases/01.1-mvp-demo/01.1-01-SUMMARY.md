# Phase 01.1 Plan 01: VLM + Script Generation Modules Summary

**One-liner:** Qwen3-VL visual notes via vLLM offline inference + Korean lecture script generation via `claude -p` async subprocess, with text-grounded prompting and per-slide JSON output.

## What Was Built

### Task 1: VLM Visual Notes Module (`lecture_auto/pipeline/vlm.py`)

- `VlmNote` Pydantic schema: `slide_index`, `visual_summary`, `key_elements`, `layout_relations`, `teaching_points`, `possible_confusions`
- `load_vlm(model_path)` — loads Qwen3-VL-8B-Instruct via `vllm.LLM`
- `build_vlm_prompt(slide, rendered_dir)` — multimodal prompt with slide PNG + parsed text (text-grounded prompting per VLM-02)
- `generate_visual_notes(llm, slides, rendered_dir, vlm_dir)` — batch inference, JSON retry on parse failure, saves `vlm_note_NNN.json`
- 6 unit tests with mocked vLLM (no GPU required), all passing

### Task 2: Script Generation Module (`lecture_auto/pipeline/script_gen.py`)

- `SlideScript` Pydantic schema: `slide_index`, `slide_number`, `target_seconds`, `script`, `keywords`, `transition_to_next`
- `build_script_prompt(...)` — Korean university professor persona, LectureStyle params embedded, prev/current/next slide context window (SCRIPT-02), VLM visual notes included
- `call_claude(prompt)` — `asyncio.create_subprocess_exec("claude", "-p", prompt)` with stderr error propagation
- `generate_scripts(...)` — sequential processing, `target_seconds = (target_minutes * 60) / slide_count`, saves `script_NNN.json`
- `_parse_script_json()` — strips markdown code fences from Claude output
- 8 unit tests with mocked subprocess, all passing
