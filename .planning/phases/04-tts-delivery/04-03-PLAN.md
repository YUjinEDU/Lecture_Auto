**1. Create `portal/components/lecture/VoiceRecorder.tsx`:**

"use client" component. Per D-01 (both browser recording and file upload), D-02 (one-time registration), D-03 (3-second clip).

Props: `{ onRegistered: (status: { registered: boolean }) => void }`

State: `recording` (boolean), `countdown` (number), `uploading` (boolean), `registered` (boolean), `error` (string | null)

**Check registration on mount:** `GET ${GPU_API_URL}/jobs/voice/status?professor_id=default`. If registered=true, show "Voice registered" success state.

**Browser recording flow:**
- Button: "Record Voice (3s)" with `Mic` icon (Lucide)
- On click: `navigator.mediaDevices.getUserMedia({ audio: true })`
- Create `MediaRecorder(stream, { mimeType: "audio/webm;codecs=opus" })`
- Start recording, show 3-second countdown (3... 2... 1...)
- Auto-stop after 3000ms via `setTimeout`
- On stop: create `Blob`, build `FormData` with field `audio_file`, POST to `${GPU_API_URL}/jobs/voice/register`
- On success: call `onRegistered({ registered: true })`, show success state

**File upload flow:**
- Secondary button: "Upload WAV" with `Upload` icon (Lucide)
- Hidden `<input type="file" accept=".wav,audio/wav">` triggered on click
- On file select: build `FormData`, POST to `${GPU_API_URL}/jobs/voice/register`
- Same success handling as recording

**Visual states:**
- Default: Two buttons (Record / Upload) side by side
- Recording: Pulsing red dot + countdown number (3... 2... 1...)
- Uploading: Spinner + "Uploading..."
- Registered: Green checkmark + "Voice registered" + "Re-record" small link
- Error: Red text below buttons

Styling: Use Tailwind classes matching 03-UI-SPEC.md design system. Card with md padding (16px), rounded-lg border.

**1. Create `portal/components/lecture/TTSProgressFooter.tsx`:**

"use client" component. Clone the SSE pattern from the Phase 3 script review page.

Props: `{ jobId: string, onComplete: () => void }`

State: `current` (number), `total` (number), `status` (string), `connected` (boolean)

**SSE connection:**
- On mount: create `EventSource(${GPU_API_URL}/jobs/${jobId}/tts/progress)`
- Handle `initial` event: set current/total/status from data
- Handle `progress` event: update current/total/status
- Handle `complete` event: call `onComplete()`, close EventSource
- Handle `error` event: set connected=false, show "Reconnecting..."
- Cleanup: close EventSource on unmount

**Visual layout** (matching 03-UI-SPEC.md ProgressFooter):
- Sticky bottom, h-16 (64px), flex row, items-center, justify-between, px-8 (32px)
- Background: white with top border `border-t border-gray-200`
- Left: Progress bar (h-2, rounded-full, bg-gray-200 track, bg-blue-600 fill) + label "Generating audio... {current}/{total}" (14px, muted)
- Right: Connection status dot (green when connected, amber when reconnecting)
- Progress bar width: `max-w-[400px] flex-1`
- Fill width: `(current / total) * 100`%
