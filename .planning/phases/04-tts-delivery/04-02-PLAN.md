**1. Create `lecture_auto/api/routes/tts.py`:**

Router prefix: `/jobs`, tags: `["tts"]`. Endpoints:

**POST `/voice/register`** (per D-01, D-02, D-03):
- Accept `UploadFile` named `audio_file` (WAV or WebM)
- Accept optional `professor_id: str = "default"` form field (MVP: always "default" per deferred INFRA-03)
- If content_type contains "webm": call `convert_webm_to_wav(await audio_file.read())`
- Otherwise: use raw bytes
- Call `save_voice_ref(professor_id, wav_bytes)`
- Return `VoiceRegisterResponse(professor_id=professor_id, voice_ref_path=str(ref_path), status="registered")`

**GET `/voice/status`** :
- Accept optional `professor_id: str = "default"` query param
- Call `get_voice_ref(professor_id)`
- Return `{"professor_id": professor_id, "registered": ref_path is not None}`

**GET `/{job_id}/audio/{slide_number}/wav`** (per D-04, TTS-03):
- Serve individual WAV file from `job_paths.audio_dir / f"audio_{slide_number:03d}.wav"`
- Return `FileResponse(str(wav_path), media_type="audio/wav")`
- 404 if file does not exist

**POST `/{job_id}/tts/{slide_number}/regenerate`** (per D-05):
- Accept `job_id`, `slide_number` path params
- Get voice_ref via `get_voice_ref("default")`
- Call `regenerate_slide_tts_task.apply_async(args=[job_id, slide_number, str(voice_ref) if voice_ref else None], queue="gpu_queue")`
- Return `TTSRegenerateResponse(job_id=job_id, slide_number=slide_number, task_id=task.id, status="regenerating")`

**GET `/{job_id}/tts/progress`** (SSE):
- Clone the pattern from `scripts.py:stream_script_progress` exactly
- Filter for `stage == "tts"` events (not "script")
- Use `EventSourceResponse(event_generator(), ping=15)`
- Subscribe to `f"job:{job_id}:progress"` channel
- Send initial state from `get_last_progress(job_id)` if stage is "tts"

- Return `StreamingResponse(zs, media_type="application/zip", headers={"Content-Disposition": f"attachment; filename=lecture_{job_id}.zip"})`
