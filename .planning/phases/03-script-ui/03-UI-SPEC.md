# Phase 03 — UI Design Contract

> Visual and interaction contract for the Script Review UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Context:** The Next.js portal is an external repo deployed on Vercel. This contract defines a self-contained page component set that integrates into that portal. No component library is assumed. The page connects directly to the GPU server FastAPI API (not proxied through Next.js API routes).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (vanilla React + Tailwind CSS assumed from portal) |
| Icon library | Lucide React (lightweight, tree-shakeable, already common in Next.js ecosystems) |
| Font | Inherit from portal (system font stack fallback: `"Pretendard", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`) |

**Rationale:** The portal already has its own styling. This spec defines structural layout, interaction states, and copywriting. Colors and fonts inherit from the portal's existing theme. If the portal uses Tailwind, the executor maps tokens below to Tailwind classes. If not, the executor uses CSS custom properties.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, badge padding |
| sm | 8px | Thumbnail list item padding, inline spacing |
| md | 16px | Panel internal padding, card padding |
| lg | 24px | Panel gap (between left/right panels), section spacing |
| xl | 32px | Page-level horizontal padding |
| 2xl | 48px | Top/bottom page margins |
| 3xl | 64px | Not used in this phase |

Exceptions: Slide thumbnail width fixed at 160px (not on scale; dictated by aspect ratio). Minimum touch target 44px for mobile-accessible buttons (approve, regenerate).

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 600 (semibold) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Script text (editor) | 16px | 400 (regular) | 1.75 |

**Note:** Script editor text uses 1.75 line-height for readability during review/editing. This is the professor's primary reading surface. Korean text benefits from extra line spacing.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-primary)` / `#FFFFFF` fallback | Page background, editor background |
| Secondary (30%) | `var(--bg-secondary)` / `#F8F9FA` fallback | Slide list panel background, status badges |
| Accent (10%) | `var(--accent)` / `#2563EB` fallback | See reserved list below |
| Destructive | `var(--destructive)` / `#DC2626` fallback | Destructive actions only |

Accent reserved for:
1. "Approve Scripts" primary CTA button (background fill)
2. Selected slide thumbnail border (active indicator)
3. Progress bar fill
4. "Regenerate" button text (text-only button, not filled)
5. SSE connection status dot (connected)

**Semantic colors (additional):**
| State | Value | Usage |
|-------|-------|-------|
| Success | `#16A34A` | Generation complete badge, approved status |
| Warning | `#F59E0B` | "Edited" badge on manually edited slides |
| Muted | `#9CA3AF` | Disabled button text, placeholder text, slide numbers |

## Component Inventory

### Layout: 2-Panel Split (D-01)

```
+--------------------------------------------------+
| Page Header: "Script Review" + Job metadata      |
+--------------------------------------------------+
|              |                                     |
|  Slide List  |  Detail Panel                      |
|  (left)      |  (right)                           |
|  w=240px     |  flex-1                            |
|  fixed       |                                     |
|              |  +-------------------------------+  |
|  [thumb 1]*  |  | Slide PNG (max-h: 360px)     |  |
|  [thumb 2]   |  +-------------------------------+  |
|  [thumb 3]   |  | Script Editor (textarea)      |  |
|  ...         |  | h: remaining space            |  |
|              |  +-------------------------------+  |
|              |  | Action Bar                     |  |
|              |  | [Regenerate]  [Save]           |  |
+--------------------------------------------------+
| Footer: Progress Bar + [Approve Scripts] CTA     |
+--------------------------------------------------+
```

- Left panel: Fixed 240px width, scrollable slide list
- Right panel: Flex-1, divided into slide preview (top) + script editor (bottom)
- Footer: Sticky bottom, contains progress and approval CTA

### Component 1: SlideListPanel

| Property | Value |
|----------|-------|
| Width | 240px fixed |
| Background | Secondary (`#F8F9FA`) |
| Scroll | Vertical overflow-y auto |
| Item height | Auto (thumbnail 160x90 + label) |

**Slide List Item:**
- Thumbnail: 160px wide, 90px tall (16:9 aspect ratio), object-fit cover
- Below thumbnail: Slide number label (14px, muted)
- Below label: Status badge (see states below)
- Selected state: 2px accent border-left on item, white background
- Hover state: Background `#F0F0F0`
- Padding: 8px per item, 4px gap between items

**Status badges per slide:**
| State | Badge | Color |
|-------|-------|-------|
| Generating | "Generating..." | Muted text, pulse animation |
| Generated | "Generated" | Success background, white text |
| Edited | "Edited" | Warning background, dark text |
| Empty | "No script" | Muted background, muted text |
| Error | "Error" | Destructive background, white text |

### Component 2: SlidePreview

| Property | Value |
|----------|-------|
| Max height | 360px |
| Width | 100% of detail panel |
| Object fit | contain (preserve aspect ratio) |
| Background | `#F0F0F0` (contrast behind white slides) |
| Border | 1px solid `#E5E7EB` |
| Border radius | 8px |

Image source: `${GPU_API_URL}/jobs/${jobId}/slides/${slideNumber}/png`

### Component 3: ScriptEditor

| Property | Value |
|----------|-------|
| Element | `<textarea>` (D-discretion: textarea chosen over rich editor) |
| Font | 16px, regular 400, line-height 1.75 |
| Min height | 200px |
| Resize | vertical only |
| Placeholder | "Script will appear after generation..." |
| Border | 1px solid `#D1D5DB`, focus: 2px accent |
| Border radius | 8px |
| Padding | 16px |

**Behavior:**
- Auto-saves on blur (debounce 500ms) via PUT `/jobs/{jobId}/scripts/{slideNumber}`
- Shows "Saving..." indicator during API call
- Shows "Saved" with checkmark for 2 seconds after successful save
- Disabled (readonly + muted background) while script is being generated for this slide

### Component 4: ActionBar

| Property | Value |
|----------|-------|
| Layout | Flex row, justify-end, gap 8px |
| Padding | 16px horizontal, 8px vertical |
| Border top | 1px solid `#E5E7EB` |

**Regenerate Button:**
- Style: Text button (no fill), accent color text
- Icon: `RotateCcw` (Lucide) 16px, left of text
- Label: "Regenerate"
- Behavior: Calls POST `/jobs/{jobId}/scripts/{slideNumber}/regenerate`
- If slide is edited (D-04): Shows confirmation dialog before proceeding

**Save Button:**
- Style: Outlined button, accent border
- Label: "Save"
- Behavior: Same as auto-save but manual trigger
- Disabled when no changes

### Component 5: ProgressFooter

| Property | Value |
|----------|-------|
| Position | Sticky bottom |
| Height | 64px |
| Background | Dominant with top border |
| Layout | Flex row, items-center, justify-between |
| Padding | 0 32px |

**Progress Bar:**
- Height: 8px, border-radius 4px
- Track: Secondary color
- Fill: Accent color
- Width: Flex-1, max-width 400px
- Label: "Generating scripts... {current}/{total}" (14px, muted)

**Approve Button (Primary CTA):**
- Style: Filled button, accent background, white text
- Size: 44px height (touch target), padding 0 24px
- Label: "Approve Scripts"
- Icon: `CheckCircle` (Lucide) 20px, left of text
- Disabled state (D-06): When any slide has empty script -- reduced opacity 0.5, cursor not-allowed
- Behavior: POST `/jobs/{jobId}/scripts/approve` -- triggers TTS (D-05)

### Component 6: RegenerateConfirmDialog (D-04)

## Interaction States

### Page Load States

| State | What Displays |
|-------|---------------|
| Loading job | Skeleton: left panel = 5 gray rectangles, right panel = gray rectangle + gray lines |
| Scripts generating | Slide list fills progressively, SSE progress in footer |
| Scripts complete | All slides show "Generated" or "Edited" badges |
| Error (job not found) | Full-page error state (see copywriting) |

### SSE Connection (UI-03)

| Event | UI Response |
|-------|-------------|
| `progress` | Update progress bar, update individual slide badge |
| `complete` | Close EventSource, fetch all scripts, enable approve button |
| `error` | Show error banner at top of page, retry connection after 3s (max 3 retries) |
| Connection lost | Show "Reconnecting..." banner, EventSource auto-reconnects |

**EventSource URL:** `${GPU_API_URL}/jobs/${jobId}/scripts/progress`

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` / `Cmd+S` | Save current script (prevent default browser save) |
| `Escape` | Close confirmation dialog |
| `Up Arrow` / `Down Arrow` | Navigate slide list (when slide list is focused) |

## Responsive Behavior

| Breakpoint | Layout |
|------------|--------|
| >= 1024px | 2-panel split (240px + flex-1) as specified |
| 768px - 1023px | 2-panel split, left panel collapses to 180px, thumbnails shrink to 120x68 |
| < 768px | Single column: slide selector dropdown replaces left panel, detail panel full width |

**Note:** Primary target is desktop (professor uses desktop environment per Out of Scope). Tablet/mobile are graceful degradation, not primary design targets.
