<interfaces>
<!-- API endpoints from Plan 02 that this UI consumes -->

FastAPI Script Routes (base: GPU_API_URL):
```
GET    /jobs/{job_id}/scripts           -> ScriptResponse[]
PUT    /jobs/{job_id}/scripts/{slide}   -> ScriptResponse (body: {script, keywords?, transition_to_next?})
POST   /jobs/{job_id}/scripts/{slide}/regenerate?force=bool -> {job_id, slide_number, task_id, status}
POST   /jobs/{job_id}/scripts/approve   -> {job_id, total_slides, tts_task_id, status}
GET    /jobs/{job_id}/scripts/progress  -> SSE stream (events: initial, progress, complete)
GET    /jobs/{job_id}/slides/{slide}/png -> image/png
```

ScriptResponse shape:
```typescript
interface ScriptResponse {
  slide_index: number;
  slide_number: number;
  target_seconds: number;
  script: string;
  keywords: string[];
  transition_to_next: string;
  edited: boolean;
  edited_at: string | null;
}
```

SSE Progress event shape:
```typescript
interface ProgressEvent {
  job_id: string;
  stage: string;   // "script"
  current: number;
  total: number;
  percent: number;
  status: string;  // "processing" | "done" | "skipped" | "error"
}
```

         slide_index: number;
         slide_number: number;
         target_seconds: number;
         script: string;

    2. Create `portal/app/scripts/[jobId]/lib/api.ts`:
       ```typescript
       const API_URL = process.env.NEXT_PUBLIC_GPU_API_URL ?? "http://localhost:8000";

       export async function fetchScripts(jobId: string): Promise<ScriptResponse[]>
       // GET ${API_URL}/jobs/${jobId}/scripts

       export async function updateScript(jobId: string, slideNumber: number, body: {script: string, keywords?: string[], transition_to_next?: string}): Promise<ScriptResponse>
       // PUT ${API_URL}/jobs/${jobId}/scripts/${slideNumber}

       export async function regenerateScript(jobId: string, slideNumber: number, force: boolean = false): Promise<{job_id: string, slide_number: number, task_id: string, status: string}>
       // POST ${API_URL}/jobs/${jobId}/scripts/${slideNumber}/regenerate?force=${force}

       export async function approveScripts(jobId: string): Promise<{job_id: string, total_slides: number, tts_task_id: string | null, status: string}>
       // POST ${API_URL}/jobs/${jobId}/scripts/approve

       export function getSlideImageUrl(jobId: string, slideNumber: number): string
       // returns `${API_URL}/jobs/${jobId}/slides/${slideNumber}/png`

       export function getProgressUrl(jobId: string): string
       // returns `${API_URL}/jobs/${jobId}/scripts/progress`
       ```

       All fetch functions: include `headers: {"Content-Type": "application/json"}`, throw on !response.ok with error detail from body.

    3. Create `portal/app/scripts/[jobId]/hooks/useSSEProgress.ts`:
       - `'use client'` directive
       - `export function useSSEProgress(jobId: string, enabled: boolean)`:
         - Returns `{ progress: ProgressEvent | null, isConnected: boolean, isComplete: boolean }`
         - Creates `new EventSource(getProgressUrl(jobId))` when enabled
         - Listens for "initial", "progress", "complete" events
         - On "complete": set isComplete=true, close EventSource
         - On error: retry up to 3 times with 3-second delay (per UI-SPEC SSE Connection section)
         - Cleanup: close EventSource on unmount or when enabled changes to false
         - Returns null progress when not connected

    4. Create `portal/app/scripts/[jobId]/hooks/useScripts.ts`:
       - `'use client'` directive
       - `export function useScripts(jobId: string)`:
         - Returns `{ scripts: ScriptResponse[], loading: boolean, error: string | null, refetch: () => void, updateLocal: (slideNumber: number, updated: ScriptResponse) => void }`
         - Fetches scripts on mount via fetchScripts()
         - `updateLocal` updates the script in local state without refetching (for optimistic UI after save)
         - `refetch` re-fetches all scripts from API
