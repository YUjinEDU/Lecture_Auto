       Implementation:

       - Load VLM notes from job_paths.vlm_dir (vlm_note_{NNN}.json per slide)

         f. publish_progress(job_id, "script", i+1, total, "done")
       - On error: publish_progress(job_id, "script", i+1, total, "error"), raise self.retry(exc=exc, countdown=60)

       - Return {"job_id": job_id, "total": total, "skipped": skipped}

       - Read existing script_{slide_number:03d}.json (404 if missing)
