# 교수님 강의 자동화 프로젝트 문서 패키지

이 디렉터리는 `PPT 한 파일 입력 -> 파싱 -> VLM 해설 노트 -> 최종 스크립트` 파이프라인 구축을 위한 공식 프로젝트 문서 모음이다.

## 구성
- `01_프로젝트_기획서.md`: 목표, 목적, 범위, 성공 기준
- `02_요구사항_명세서.md`: 기능/비기능 요구사항, 입력/출력 계약
- `03_기술_아키텍처.md`: 전체 시스템 구조, 데이터 흐름, 모듈 경계
- `04_파이프라인_모듈_설계.md`: 실제 코드 모듈 구조와 인터페이스
- `05_개발_로드맵.md`: 단계별 일정과 산출물
- `06_평가_위험관리_운영정책.md`: 품질평가, 리스크, 운영정책
- `07_디렉터리_환경설정_표준.md`: IDE 작업 표준, 폴더 구조, 설정값

## 권장 사용 순서
1. `01_프로젝트_기획서.md`
2. `02_요구사항_명세서.md`
3. `03_기술_아키텍처.md`
4. `04_파이프라인_모듈_설계.md`
5. `07_디렉터리_환경설정_표준.md`
6. `05_개발_로드맵.md`
7. `06_평가_위험관리_운영정책.md`

## 핵심 원칙
- PPT 구조 파싱과 시각 이해를 분리한다.
- VLM은 최종 강의문 작성기가 아니라 시각 해설 노트 생성기로 사용한다.
- 모든 단계는 중간 산출물을 JSON으로 남긴다.
- 재실행은 슬라이드 단위로 가능하게 만든다.
- 교수님 검수 루프를 전제로 설계한다.
