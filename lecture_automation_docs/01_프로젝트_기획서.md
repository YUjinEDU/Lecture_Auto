# 01. 프로젝트 기획서

## 1. 프로젝트명
교수님 강의 자동화 파이프라인 구축

## 2. 배경
교수님이 보유한 대량의 PPT 강의자료를 기반으로, 강의 설명 스크립트를 자동 생성하고 이후 TTS 및 영상화 단계로 연결할 수 있는 내부용 자동화 시스템이 필요하다.

## 3. 목적
- 기존 강의자료를 재활용 가능한 디지털 강의 자산으로 전환
- 반복 강의, 보강 자료, 온라인 학습용 콘텐츠 제작 시간 단축
- 교수님 설명 스타일을 유지한 스크립트 초안 자동 생성
- 이후 TTS/자막/영상 생성 모듈과 자연스럽게 연동 가능한 구조 확보

## 4. 목표
### 정량 목표
- PPT 1개 입력 시 슬라이드별 구조 파싱 100% 수행
- 모든 슬라이드에 대해 이미지 렌더링 및 VLM 해설 노트 생성
- 슬라이드별 최종 스크립트 JSON 생성 성공률 95% 이상
- 재실행 시 특정 슬라이드만 부분 재생성 가능

### 정성 목표
- 텍스트가 적은 이미지/도식 중심 슬라이드에서도 설명 품질 확보
- 강의 대상과 목표 시간에 맞춘 설명 밀도 조절 가능
- 교수님 검수와 수정이 쉬운 산출물 형식 제공

## 5. 범위
### 포함
- PPTX 구조 파싱
- 슬라이드 이미지 렌더링
- VLM 기반 visual notes 생성
- LLM 기반 최종 스크립트 생성
- JSON/Markdown 기반 산출물 저장

### 제외(1차)
- TTS 음성 합성
- 자막 싱크 및 강의 영상 렌더링
- LMS 업로드 자동화
- 실시간 웹 편집기

## 6. 성공 기준
- 교수님이 샘플 강의 1개를 보고 수정 가능한 수준의 스크립트를 얻는다.
- 슬라이드별 산출물이 독립 저장되어 재생성이 쉽다.
- 코드 구조가 후속 TTS/Remotion 단계까지 확장 가능하다.
