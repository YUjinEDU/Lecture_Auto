# 03. 기술 아키텍처

## 1. 아키텍처 원칙
- 구조 파싱과 시각 이해를 분리한다.
- 모든 단계는 독립 실행 가능해야 한다.
- 모델 출력은 스키마 검증 후 다음 단계로 넘긴다.
- 사람이 읽는 결과물과 시스템이 읽는 결과물을 동시에 남긴다.

## 2. 전체 흐름
```text
[PPTX]
  -> [PPT Parser]
  -> [Slide Manifest JSON]
  -> [Renderer]
  -> [Slide PNGs]
  -> [VLM Visual Notes]
  -> [LLM Script Writer]
  -> [Validated Slide Scripts]
  -> [Professor Review Pack]
```

## 3. 핵심 구성 요소
### 3.1 Parser Layer
- python-pptx 기반 구조 추출
- 제목, 본문, notes, shape metadata 추출

### 3.2 Rendering Layer
- LibreOffice CLI로 PPTX -> PDF
- PDF 페이지를 PNG로 변환

### 3.3 VLM Layer
- 모든 슬라이드를 이미지 기반으로 분석
- 차트, 도식, 표, 사진, 강조 영역을 설명 가능한 구조로 정리

### 3.4 Script Layer
- 슬라이드 구조 + 시각 노트 + 강의 조건을 입력받아 최종 설명문 생성
- 목표 시간에 맞는 분량 조절

### 3.5 Validation Layer
- Pydantic 기반 JSON 스키마 검증
- 누락 필드와 형식 오류 체크

## 4. 설계 포인트
- VLM이 최종 스크립트를 직접 쓰지 않게 한다.
- 슬라이드 단위 실행과 재실행을 지원한다.
- 앞뒤 슬라이드 맥락을 입력에 포함해 흐름을 유지한다.
