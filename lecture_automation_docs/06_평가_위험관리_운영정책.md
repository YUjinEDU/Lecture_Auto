# 06. 평가, 위험관리, 운영정책

## 1. 품질 평가 항목
- 내용 정확성
- 설명 충실도
- 시각 요소 반영 정도
- 강의 흐름 자연스러움
- 목표 시간 적합성
- 교수님 스타일 유사성

## 2. 주요 리스크
### R1. 슬라이드 텍스트 부족
대응: VLM visual notes 비중 확대, 과거 강의자료 retrieval 연결

### R2. 차트/도식 해석 오류
대응: 유형별 프롬프트 분리, 교수님 검수 필수

### R3. 스크립트 과장/환각
대응: 구조 정보와 이미지 근거에 없는 설명 금지, 스키마 검증 강화

### R4. 긴 강의에서 흐름 붕괴
대응: 슬라이드 단위 생성 후 coherence refinement 수행

## 3. 운영정책
- 원본 PPT는 읽기 전용으로 보관
- 모든 실험은 job 단위 작업 디렉터리에서 수행
- 모델 버전, 프롬프트 버전, 설정값을 모두 기록
- 교수님 검수본과 자동 생성본을 분리 보관
